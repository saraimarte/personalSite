If you want to be able to move the cube yourself then the only new things you have to do are the following, 

<DropDown title = "Code">

**1.** Import Orbit Controls at the top of the file 

<Code lang = "javascript" fileName = "example.js" code = {
`import { OrbitControls } from 'three/examples/jsm/controls/OrbitControls.js';`
}/>
OrbitControls is part of the Three.js examples folder (not the core library). It’s a helper class that makes it easy to orbit (rotate), zoom, and pan the camera around a target scene/object using mouse or touch gestures.

In other words, it gives you a way to move the camera just by dragging or scrolling, rather than manually adjusting the camera’s position and rotation in your code.

**2.** Create the controls and pass in camera and canvas. 

<Code lang = "javascript" fileName = "example.js" code = {
`const controls = new OrbitControls(camera, canvas);
controls.enableDamping = true;  // This adds smooth movement`
}/>

**3.** Update the controls within the animation loop.

<Code lang = "javascript" fileName = "example.js" code = {
`controls.update();`
}/>

Here is the full code,

camera.position.y = 2
camera.position.z = 2
camera.lookAt(mesh.position)
scene.add(camera)

    controls.update();
