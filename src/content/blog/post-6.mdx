<Section t = '1 | How to clone a specific branch from a git repository'>

First, create a folder anywhere in your files. Open the folder in VSCode.   

Using VSCode's terminal (CTRL + J in Windows), enter the following command, 

<Code lang="git" fileName="Command" code={`git clone -b branchName repoURL`} />

For example, if I want to clone the lesson-01 branch from a repo who's url is https://github.com/saraimarte/Repository.git then the command would be 

<Code lang="git" fileName="Command" code={`git clone -b lesson-01 https://github.com/saraimarte/Repository.git`} />

</Section>


<Section t = '2 | How to create a branch'>

<Code lang="git" fileName="Command" code={`git branch name_of_the_branch`} />

For example, if you want to create a branch called 'version2' then you would enter, 

<Code lang="git" fileName="Command" code={`git branch version2`} />

This command only *creates* the branch. 

To actually switch to working in the branch you need to follow snippet 3. 

</Section>

<Section t = '3 | How to switch to working in a branch'>

<Code lang="git" fileName="Command" code={`git checkout name_of_the_branch`} />

If you have a branch called 'version2' and want to switch to working on it then you want to *checkout* that branch (take a look at it), so the command would be, 

<Code lang="git" fileName="Command" code={`git checkout version 2`} />

</Section>

<Section t = '4 | How to create and switch to a branch at the same time'>

<Code lang="git" fileName="Command" code={`git checkout -b name_of_branch`} />

For example, if you want to create a branch called 'version2' and immediately switch to it to start working on it then this is the command, 

<Code lang="git" fileName="Command" code={`git checkout -b version2`} />

What does the **-b** mean? Branch. 

You have to use -b instead of branch if you want to create and switch to a branch at the same time. That is the syntax git accepts. 

</Section>


<Section t = '5 | How to see your commit history'>

The following let's you see all the commits you have made in the current branch that you are in. 

<Code lang="git" fileName="Command" code={`git log`} />

If you want to see the commit history for a specific branch you can run the following, 

<Code lang="git" fileName="Command" code={`git log name_of_branch`} />

If you don't like the format that the commits are given to you, you can get the last n commits in one line from a specific branch like so, 

<Code lang="git" fileName="Command" code={`git log -n --oneline name_of_branch`} />

For example, if I want the last 2 commits for a branch called 'version2' then, 

<Code lang="git" fileName="Command" code={`git log -2 --oneline version2`} />


</Section>



<Section t = '6 | How to undo a commit'>

First, you need to get the id of the commit. Let's call it **commitID**. 

To get the **commitID**, you need to look at the commit history or *logs*. To do that, see snippet 5. 

Run, 

<Code lang="git" fileName="Command" code={`git log -1`} /> to see the previous commit made. You will also see the **commitID**. Copy it. 

Then run the following with **commitID** paste it to undo the last commit. 

<Code lang="git" fileName="Command" code={`git revert commitID`} />. 



</Section>
