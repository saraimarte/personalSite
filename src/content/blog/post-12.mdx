**3.** Create an **index.html** file inside the project folder and paste in the following code.

<Code lang = "html" fileName = "index.html" code = {
`<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta http-equiv="X-UA-Compatible" content="IE=edge">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<script src = "/socket.io/socket.io.js"></script>
<body>
  
  <!--Create a form  -->
  <form action = "">

  <!--Create an input box for the message -->
    <input id = "m"/>

  <!--Create button to send message -->
    <button>Send</button>

  </form>

</body>

<script>

// Initialize socket connection
const socket = io();

//Get the form
const form = document.querySelector('form');

// Everytime you click send on the form...
form.addEventListener('submit', function(e){
  //Prevent Page Refreshing
  e.preventDefault();

  // Take the input message 
  const input = document.getElementById('m');

  //Emit the message to the server...
  //This only works if the server receives it. 
  // Think of chat message as an event 
  // In the server you will write some code to listen for this event
  // You also pass in what you want to send in this case msg
  socket.emit('new message', input.value);

  //Clear the input box after sending the message
  input.value = '';
});
  
</script>

</html>`}/>

**4.** Create an **app.js** file inside the project folder and paste in the following code.

<Code lang = "javascript" fileName = "app.js" code = {
`//Create express application
const app = require('express')();

// Create http server 

const http = require('http').Server(app);

// Create instance of socket

const io = require('socket.io')(http);

// Create route - tell server to send index.html to that route

app.get('/', function(req, res){
    res.sendFile(__dirname + '/index.html');
});

//On connection...
io.on("connection", function(socket){
    console.log('A user connected');

    //on new message...
    socket.on('new message', function(msg){
    //console the message
        console.log(msg);
    });

});

//Tell server to listen to port 3000

http.listen(3000, function(){
    console.log("Connected");
})`}/>

**5.** In the terminal, make sure you cd into the project folder with **cd ./project** then run **node app.js**. Then go to http://localhost:3000/ and you should see the input box like so,

# Going further 

## What if you want to send multiple messages instead of one?

Let's say that every time we send a message we also want to send a color. 

In your form event listener, edit your emit so that it takes in two things instead of one, a message and a color. 

<Code lang = "javascript" fileName = "index.html" code = {
`socket.emit('new message', {
  message: input.value,
  color: "#ffffff"
});`}/>

and in **app.js**, 

<Code lang = "javascript" fileName = "app.js" code = {
` socket.on('new message', function(msg, color){ //Now we take in both msg and color
      //console the message and color
      console.log(msg);
      console.log(color);
});`}/>

<video controls>
  <source src={vid2} type="video/mp4"/>
</video>

Notice how even though the messages are different, the color is always the same: #ffffff, because we told it to return that exact color. 

But that's not really useful. 

Let's say that we want to give each client a username and send that to the server instead of a color. 

Instead of a color, let's prompt the client for a username and return that along with the message they sent.  

In your script tag at the top before the **const socket = io();** write the following, 

<Code lang = "javascript" fileName = "index.html" code = {
`let usernameVariable = prompt("Enter Username: ");`}/>

then in the form event listener edit your emit to send out the username instead of a color.

<Code lang = "javascript" fileName = "index.html" code = {
`socket.emit('new message', {
  message: input.value,
  username: usernameVariable
});`}/>

and in **app.js**, 

<Code lang = "javascript" fileName = "app.js" code = {
` socket.on('new message', function(msg, username){ //Now we take in both msg and username
      //console the message and color
      console.log(msg);
      console.log(username);
});`}/>
