Recall: A PBR (Physically Based Rendering) texture for an object is a set of images that simulate how light interacts with the object. 

<Card img = {img1} alt = "PBR Files"/>

Now, you can take the object and apply the PBR files to the object in one step using the Node Wrangler add-on in Blender. 

"It can automatically set up Physically Based Rendering (PBR) materials from texture maps with a single shortcut (Ctrl+Shift+T)."

https://extensions.blender.org/add-ons/screencast-keys/

 To display keyboard input as text in Blender, you'll need to enable the "Screencast Keys" add-on. Once enabled, you can toggle it on/off to show or hide the text output of your keystrokes on the screen.
